# R-003 Self-hosted LLM, no Claude Code

- Source: owner, 2026-10-03 · Class: v1 must · Status: decided (D11, D14)

The model used for structuring, matching and generation is deployed by the owner. The platform does not call Claude Code or
any vendor API. Consequence: an OpenAI-compatible endpoint abstraction (`LlmProvider`), an in-house coding agent, a P0
endpoint probe and a P1 model comparison. The owner names the candidate models before P1.
