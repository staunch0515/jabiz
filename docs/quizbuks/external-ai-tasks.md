## E3 日本的赠品规则与有奖答题（Gemini）

贴给它：`docs/quizbuks/legal/contest-rules.ja.md`、`docs/quizbuks/02-design.md` 中"奖励"的部分（或 `docs/quizbuks/plans/Q22-reward-methods.md`）。

```
あなたは日本の景品表示法（景品規制）と特定商取引法に詳しい調査担当です。添付は当サービスの仕組みと「懸賞規約」の草案です。

サービスの仕組み：スポンサー（企業）がクイズを公開し、利用者が無料で回答し、合格点以上で「Kudos」（サービス内ポイント）、店頭で受け取る商品、電子ギフト（コード）などの賞品を受け取る。スポンサーは賞品の内容と人数の上限を決める。参加に商品購入は不要だが、一部のクイズには参加料（Kudos）がある。

調べてほしいこと（各項目に根拠の条文・ガイドライン・消費者庁の資料のリンクを付けて）：
1. このような「クイズに合格すると賞品」は、一般懸賞・共同懸賞・総付景品・オープン懸賞のどれに当たる可能性があるか。購入不要の場合と参加料がある場合で分けて。
2. それぞれの景品の上限額（最高額・総額）。
3. 「先着」「全員」「抽選」で扱いが変わるか。
4. 運営者（プラットフォーム）とスポンサーのどちらが景品表示法上の責任を負うか。
5. 懸賞規約に必ず書くべき事項のチェックリストと、添付の草案に足りない点。
6. スポンサーが賞品を設定する画面で、プラットフォームとして入れておくべき制限や注意書きの提案。

出力：結論の要約（1 ページ）→ 各項目の詳細と根拠。法的助言ではなく調査メモとして書き、不確かな点ははっきり書いてください。
```

```

1. 键（等号左边）一个字也不改，不增不减。
```
