# Q59 语言（2026-10-30）

需求方（2026-10-30）："所有的多语言选择要被开关控制，开关是用户自己控制。答题者控制自己的，商户控制自己的。后面我会建三个运营商，分别对应三种语言。
语言匹配也会被默认选择。也即是只有中文的客户端，可以看到中文的试题。Quiz 要加一个选择语言属性。所有的超链接和 QR code 中要有语言的信息。"
需求方确认：默认不能让不同语言的发布显示在一起；语言开关默认关（缺省只看界面语言）；已有 Quiz 的语言忽略（测试数据）。

| 期 | 内容 |
|---|---|
| **Q59a** | Quiz 的语言；答题者的内容语言开关；首页按语言筛选（本节） |
| Q59b | 所有链接与二维码带语言（`?lang=`），打开时以它为界面语言 |
| Q59c | 运营商按语言（自动指派、审核队列、结算单的语言） |

## 1. Q59a 设计

- **Quiz 的语言**：`QbQuiz.language`（日语、中文、英语之一，字典 `urn:jabiz:dict:quizbuks:content-language`）。商家新建 Quiz 时选（缺省为后台的界面语言），在标题下面可改；
  保存时不给语言即保持原样（新建时为调用者的界面语言）。复制的 Quiz 沿用来源的语言；导入的与 Shopify 店铺的取请求的语言。
- **版本**：`QbQuizVersion.language` 冻结版本生成时的语言。语言不放进内容快照，所以现有版本的内容哈希不变；只改了语言也算有变化，可以生成新版本。
- **发布卡片**：`QbPublicationCard.language` 取所发布版本的语言；切换版本（Q51）时一起换。
- **迁移**：V44 给三个只追加或普通表加 `language` 列（缺省 `ja`：已有 Quiz 是测试数据，需求方同意给一个缺省值），并给卡片建 `(language, status)` 索引；
  `qb_user_settings` 加 `content_languages`。
- **答题者的开关**：账户 → App 设置 → "Quiz 的语言"：每种语言一个开关。没有选择时跟随 App 的界面语言（切换界面语言，首页随之改变）；
  选择后保存在账户上（`QB_SETTINGS_SAVE` 的 `contentLanguages`，空即恢复跟随界面语言）；至少保留一种。
- **首页**：`qb.app.feed` 的新参数 `languages`（逗号分隔）只列这些语言的发布；App 先读设置再请求首页，不会先闪出别的语言。
  不给参数时列出全部（只为兼容；App 总是给）。链接直接打开的发布页（分享、邀请、二维码）不受开关限制，并返回它的语言。
- **商家的开关**：商家用每个 Quiz 的语言控制自己发布的语言；后台的界面语言与 Quiz 的语言各自独立。

## 2. Q59b 设计：链接与二维码带语言

- **参数**：`?lang=ja|zh|en`，即该 Quiz 的语言。
- **谁加**：
  - 商家后台的分享链接、二维码（屏幕、PNG、SVG、海报）都用 `shareLink(发布, 语言)`，语言取发布版本的语言；
  - 邀请邮件（Q25）的登录链接 `…/auth/email-link?…&to=…&lang=…`（邮件参数 `lang` 取卡片的语言，放在外层链接上：App 打开的第一个页面就是登录页）；
  - 官网：进入 App 的链接（登录、注册、条款、帮助）带页面的语言，"试答"按钮带各自 Quiz 的语言（已有 `lang` 的不改）。
  - 兑换码（店员柜台、商家的兑换页）是商家的、不属于某个发布，不带语言；App 内扫码只取路径。
- **App 怎么用**：启动时（渲染之前，`linkLanguage.ts`）读取 `lang` 并从地址中去掉。
  - **第一次使用 App 的人**（没有选过语言）以它为界面语言并记住：海报、分享、邀请带来的新用户第一眼就是该 Quiz 的语言；
  - **已经选过语言的人**保持自己的语言，链接不在背后改它；发布页照常打开（直接打开的发布不受语言开关限制）。
- **收件箱**：商家关于某个发布的通知按答题者看的语言筛选（`qb.app.inbox` 与 `qb.app.inbox-unread` 的新参数 `languages`，与首页相同；先读设置）。
  系统消息与平台公告不受影响；服务器自己读取收件箱（标记已读）时不给参数，即全部。

## 3. 未在 Q59a、Q59b 中的

- 首页卡片上不显示语言（只看一种语言时多余）；打开多种语言时再考虑加标记。
- AI 出题的语言缺省仍为后台语言（可改为 Quiz 的语言，属小改进）。
