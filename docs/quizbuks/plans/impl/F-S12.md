# F-S12 视频共享（提供方与共享目录）：实施计划

依据：`docs/quizbuks/first-launch-spec.md` F-S12（以它为准）；`Q112-video-push.md` §0、§1、§10 只作参考。
依赖：F-C1（资源库，`com.jabiz.quizbuks.asset`）、F-S1（审核去向：发起方所属的运营商审核）、F-S9（主题词）、F-S10（竖屏，`PublicationEditing.vertical` 一处）、F-S11（境外视频，`ForeignVideos.videoLinks` 一处）。
会话 S3，分支 `1.3/quizbuks-fs12-video-share`（叠在 F-S9 `1.3/quizbuks-fs9-topics` 上，后者叠在 F-S10、F-S11 上）。

## 0. 范围

一个 PR 做完规格 F-S12 的全部，**费用除外**：规格"费用按 F-M 处理"的钱的部分是 S2 的 F-M8（未开始）。本项不收费、不退费，下架结束发布的流程中留了位置（`PublicationSharedVideos.ended` 的注释"F-M8"），**费用随 F-M8**。
曝光的计数与曝光费（Q112 §2–§5）是 F-S13，视频使用台账与双方统计（Q112 §6–§7）是 F-S14，屏蔽（Q112 §8.1）是 F-S8：本项只为它们冻结卡片上的提供方。

**删除的功能：无。** 已有的行为只多两点：发布可以选一个共享视频（不选时与以前完全相同）；结束原因多一种 `SHARED_VIDEO`。

## 1. 规则（一处定义：`sharedvideo.SharedVideoRules`）

- **谁能共享什么**：发起方（权限 `qb.content.write`，已验证邮箱，未被封禁）把自己资源库中的一个**视频链接**（`VIDEO_LINK`）共享出去：链接与时长取自资源（链接须是 `VideoEmbeds.player` 认得的网站（与 F-S15 合并后：视频文件与其他 https 网页同样可以，见 F-S15 §9），时长 1–7200 秒，不全即 422 `QB_SHARED_VIDEO_ASSET_INCOMPLETE`），提供方另给**三语标题**（都必填）、**主题词**（F-S9 词表中的词，至少一个，可选的词，个数按 `qb.topic.max-per-quiz`）与**竖或横**（YouTube Shorts 链接总是竖）。
- **共享的内容不变**：共享时复制进 `QbSharedVideo`，之后提供方改资源或删资源都不影响它；要改就撤回再共享（新的一行，重新审核）。同一资源同时只有一个"待审核或共享中"的共享（部分唯一索引兜底，`QB_SHARED_VIDEO_ALREADY_SHARED`）。
- **审核一次**：平台的审批（主题 `qb.shared-video`，规则 `qb.shared-video.review` 由 `QB_SETUP` 以受控变更提出，审批人持 `qb.review.publication`），范围是提供方所属的运营商（F-S1 的审核去向）；事实 `shared` 恒为真：没有开关能跳过。没有生效的规则即 422 `QB_REVIEW_NOT_CONFIGURED`（同发布）。驳回带理由，提供方看得到，可以再共享。
- **目录**：只列"共享中"（`APPROVED`）的视频。发布向导按标题（任何语言）或提供方的公司名搜索，按主题词与竖横筛选。用自己共享的视频也可以（规格没有禁止；以后曝光费只对别人的视频收，Q112 §0-3）。
- **选用与冻结**：草稿以 `QB_PUBLICATION_SHARED_VIDEO_SET` 选一个（只能选共享中的，否则 422 `QB_SHARED_VIDEO_UNAVAILABLE`），提交时再查一次（撤回或下架了即同样拒绝）；**提交即冻结**：之后提供方撤回，已提交的发布照常用到结束。复制发布时连同所选的共享视频一起复制。审批内容（`PublicationApprovals` 的内容哈希）只在有共享视频时多一项 `sharedVideoId`（以前的哈希不变），所以发布照常审核、视频本身不再审核。
- **卡片**（上线与版本切换时冻结）：`sharedVideoId` 与 `videoProviderId`（提供方，供 F-S8 屏蔽与统计）；卡片的视频是共享视频（`VideoEmbeds.player` 的嵌入地址；与 F-S15 合并后不论哪一类都排在资料的视频之前，**播放不需要密钥**），竖横按提供方所设或 Shorts 链接（F-S10）；**例外**：版本有"看完才能答题"的视频（Q75）时卡片视频仍是它（不减少已有功能），共享视频只计入境外判断。境外（F-S11）：共享视频的链接与版本的视频链接一起由 `ForeignVideos.foreign` 判断。
- **撤回**：只有提供方，从"待审核"（同时撤回审批）或"共享中"到"已撤回"：新的发布不能再选，已提交的照常用到结束。
- **下架**：视频违法或侵权时，提供方的运营商（只限自己的发起方，别的 404）或平台（内容管理员）以 `QB_SHARED_VIDEO_TAKEDOWN`（`qb.admin.shared-video.write`，总是要求二次验证，理由必填）把"共享中"或"已撤回"的视频下架。提供方收到邮件（`qb.shared-video.taken-down`，带理由）。用到它的发布由每分钟的逐项任务 `qb.shared-video-ends`（平台决策 D42：每个发布一个事务）以 `QB_PUBLICATION_SHARED_VIDEO_END` 结束：结束原因 `SHARED_VIDEO`，**不是下架发布**（`PublicationAdmin.takenDown` 仍为假：可以复制，同一 Quiz 以后的发布照常审核，不算违约），进行中的答题照常完成；使用方收到邮件（`qb.publication.shared-video-ended`，说明不是违约）。

锁：提供方的共享 `qb.shared-videos:<提供方>` → 一个视频 `qb.shared-video:<编号>` → 平台审批的锁；下架先取运营商成员锁（`OperatorChecks.memberWhenScoped`）再取视频锁。这些流程都不取发布锁；结束发布由任务逐项在发布锁与开始锁内做，与现有锁序无关。
提交只读共享视频的状态、不取它的锁。审核期间被下架的，审批结果在上架前再查一次即不上架（§6 第 4 条）；与下架恰好并发（不需审核的提交读到下架之前的状态）时，下一分钟的任务把它结束（模板按卡片找，不按读到的状态）。

## 3. 语句数

答题路径一条语句也不加：开始与提交只读卡片，卡片上的视频照旧是一个嵌入地址（`AttemptStatementBudgetIT` 不变，已跑）。
提交、审批结果、版本切换多一个读取共享视频的步骤，没有共享视频时查询是空的 `IN ()`（平台不发语句），有时多一条锁内语句（只在这几个低频流程）。

## 6. 总控 2026-11-08 的决定（已写回规格 F-S12）

1. **主题词不并入发布**：共享视频的主题词只用于目录的搜索（`qb.sponsor.shared-videos` 的 `topic`），使用它的发布的卡片主题词仍是发布自己的（F-S9 的"只看喜欢的主题"不变）。
2. **提供方删除账号即撤回**：`QB_SPONSOR_ERASED`（Q72，账号删除后的事件消费者）在结束其发布、撤回其通知之后，读出该提供方"待审核"与"共享中"的共享视频，按编号升序以子流程 `QB_SHARED_VIDEO_ERASED_WITHDRAW`（`subProcessOnly`，`qb.shared-video.system`）逐个撤回：同 `QB_SHARED_VIDEO_WITHDRAW`（待审核的同时撤回审批），锁序账户 → 发布 → `qb.shared-videos:<提供方>` → `qb.shared-video:<编号>`。已提交的发布照常用到结束；已驳回、已下架的不动。测试 `SharedVideoIT.aDeletedProvidersVideosAreWithdrawnWhatWasSubmittedKeepsThem`。
3. **运营商的使用数只含自己的发起方**：模板按会话的数据范围计数（卡片按运营商范围），平台看到全部。保持现状。
4. **上架时再查**：审批结果 `QB_PUBLICATION_APPROVAL_RESULT` 在上架之前（与封禁、审核中过期同一处）检查已读取的共享视频：已下架即不上架，退回草稿，`rejectCode = QB_SHARED_VIDEO_TAKEN_DOWN`；通知种类按 `REJECTED`（`PublicationNotices.kindOf`），邮件 `qb.publication.rejected` 的理由是该代码在发起方语言中的文字；发起方页面的发布页同样说明（`publishing.detail` 的"已退回"，`sharedVideos.field.takenDownInReview`）。不算违约：另选视频或不用后重新提交。答题路径不变（`AttemptStatementBudgetIT` 不变）。测试 `SharedVideoIT.aReviewedPublicationWhoseVideoWasTakenDownMeanwhileDoesNotGoOn`。
