# Q100 商户资料包：导入、导出与生成（计划，2026-11-05，待确认）

需求方（2026-11-05）：
1. 商户资料加导入与导出；文件叫"商户资料包"。
2. 生成的包里可以没有图片，但包的格式要能放图片：生成 → 导入 → 在商户中心补图片 → 再导出，就是完整的备份。
3. 图片（头像、主页封面、商品图片）在包里可以是**链接**。
4. 导入商品一律**整体替换**。
5. 生成资料包的网站 **B 与 C 都做**：B 是招商站上不用登录的生成器；C 是商家后台里的"从官网生成"（Claude 读商户的官网起草）。

## 1. 决定（草案）

| # | 决定 |
|---|---|
| D-Q100-1 | **格式**：一个 JSON 文件 `<名>.quizbuks-profile.json`，`format: "quizbuks-profile"`、`schema: 1`。三部分：`basics`（公司、联系人、简介与译文、头像）、`page`（主页地址名、首选语言、标语、提供的语言与译文、封面、官网）、`products`（≤ 50 个：名称、说明与译文、价格、币种、购买链接、图片，按数组顺序）。不含店员、邮件服务器、钱包、认证、审核与同意的记录 |
| D-Q100-2 | **图片**的三种写法：省略或 `null`（没有图片）；`{ "data": "<base64>", "type": "image/jpeg" }`（内嵌，导出总是这样写）；`{ "url": "https://…" }`（链接，见 D-Q100-6） |
| D-Q100-3 | **导入只写草稿、不绕过审核**：全部内容先检查、一次报出全部问题（同 Quiz 导入：哪一部分、哪一项、什么原因），没有问题才写入；写入只经现有流程（`QB_SPONSOR_APPLY` / `QB_SPONSOR_PROFILE_SAVE`、`QB_SPONSOR_PAGE_SAVE`、`QB_PRODUCT_SAVE` / `QB_PRODUCT_DELETE`），规则与手填相同。入驻资料与主页照旧由商户自己提交审核；主页要在入驻通过后才能保存（`QB_SPONSOR_PAGE_SPONSOR_NOT_APPROVED`），入驻前导入只写基本信息，其余留待通过后再导入一次 |
| D-Q100-4 | **商品整体替换**：包里的商品替换现有的全部商品（包里没有的删除）。注意商品**保存即上线、不经审核**（现有规则），所以导入前的确认页列出将新增、修改、删除的商品 |
| D-Q100-5 | **导出**：商户中心"概况"页的"导出资料包"，图片一律内嵌；导出的文件可以原样再导入（用于备份、在测试与正式环境之间搬、交给运营商协助） |
| D-Q100-6 | **链接图片的处理（待需求方选择，见 §3）** |
| D-Q100-7 | **B：招商站的生成器** `/biz/<语言>/profile-builder`：静态页面，不用登录，数据只在浏览器中、不发给服务器；表单填写三部分、选择本机图片（内嵌）或填图片链接、预览主页效果、下载资料包；三语、手机可用 |
| D-Q100-8 | **C：商家后台的"从官网生成"**：商户输入自己的官网地址，作为外部作业由 Claude 以网页搜索与读取起草资料包（复用 AI 获客的 `ClaudeWebResearch`），只起草、不写入：商户在导入的确认页校对后才写入。计入商户的 AI 限额，须同意 `AI_NOTICE`，开关 `qb.ai.enabled`；图片只给链接 |
| D-Q100-9 | 另给一套提示词模板（同 `quiz-file-prompts.md`），让商户用其他 AI 生成资料包 |

## 3. 待选择：链接图片怎么处理

| 方案 | 做法 | 问题 |
|---|---|---|
| **甲（推荐）下载到我们这里** | 导入时由服务器按链接把图片下载下来，走上传的同一条流水线（判断类型、重新编码、去掉位置信息），之后与上传的图片完全一样；导出时内嵌 | 平台目前只允许访问声明过的主机（`ExternalService` 的白名单），要给平台加一种"下载公开图片"的能力：只限 https、拒绝内网地址（含跳转之后）、只收图片、限大小与时间。这是平台的改动，要先在 `1.3/platform` 上做（需要你同意推送平台分支） |
| 乙 直接显示链接 | 不下载，页面直接显示对方网站上的图片 | 审核后对方可以把图片换成任何内容（绕过审核）；每次显示都向对方网站暴露答题者的地址（隐私政策要改）；对方删了图就破图；导出的备份不完整 |
| 丙 只作提示 | 链接只记在导入的确认页上，提示商户自己下载后上传 | 不用改平台，但商户要多做一步 |

甲做好之前，Q100a 先按丙处理链接图片（确认页列出"这些图片请从链接下载后上传"），甲合入后自动下载。

## 4. 测试（Q100a）

- 单元：资料包的检查（每种问题一例、整体替换的差异）、导出与再导入得到相同的内容。
- IT：导入写草稿、不改变审核状态；入驻前只写基本信息；商品整体替换；别人的文件、被占用的地址名、超过上限都被拒。
- 前端：导出、导入的确认页（新增 / 修改 / 删除、问题列表）、axe；e2e：导出 → 导入同一个文件。
