# Q38 引导答题者把 App 添加到主屏幕（2026-10-27 确认）

需求方（2026-10-27）：答题者打开网站后，提示把 App 添加到手机桌面。浏览器不允许网站自动添加，只能提示、由用户点一下添加。
平台能力在 16zj（`useInstallPrompt`、`PwaInstallBanner`、`PwaInstallGuide`，设计 12 §PWA）；本阶段只决定在 App 的什么地方、什么时候提示。

1.2 已冻结只修 bug；这是需求方要求的上线前改动，不改后端、不加迁移，完成后向前合并到 1.3。

## 1. 决定（2026-10-27 全部同意）

| # | 决定 |
|---|---|
| D-Q38-1 | **时机**：答完第一份测验后在结果页提示；此后（本浏览器答过一次）在首页顶部提示。首次访问与登录页不提示（多半被直接关掉）。**Q50 修改（2026-10-28）**：在 App 内置浏览器中，"在浏览器中打开"的提示从第一次访问起显示在登录类页面与分享页 |
| D-Q38-2 | **固定入口**：账户页一直有安装入口（不能关闭；已安装时说明已安装），关掉横幅的人也能随时找到 |
| D-Q38-3 | **关闭的规则**：在任何地方关掉都算一次（同一个键 `taker`）；30 天内不再出现，关掉 3 次后不再出现（平台缺省） |
| D-Q38-4 | **App 内置浏览器**（LINE、微信、Instagram 等）：提示"请在 Safari / Chrome 中打开"，不显示安装指引 |
| D-Q38-5 | **iOS**：分步指引（"分享"可能在"…"里）；说明桌面 App 须再登录一次（存储与 Safari 分开） |
| D-Q38-6 | **只在手机与平板**：电脑上不提示 |

## 2. 实现

- `quizbuks-web/app/src/install.tsx`：`ResultInstallOffer`（结果页，记下"答过一次"）、`HomeInstallOffer`（首页，答过一次之后）、`AccountInstallEntry`（账户页）。
- 平台的横幅、指引与三语文字都来自 `@jabiz/ui`，App 不自己判断浏览器或监听 `beforeinstallprompt`。

## 3. 测试

- App 单元测试 `install.test.tsx`：答完之前首页不提示、之后提示；账户页的入口不能关闭；电脑上不提示。
- e2e `install.spec.ts`（打包的应用，手机尺寸）：iPhone 的账户页显示"分享"菜单的指引与再登录的说明（axe）；Android 上把浏览器的 `beforeinstallprompt`
  交给页面，页面不显示浏览器自己的横条，点"安装"弹出一次浏览器的确认，接受后显示已安装。

## 4. 上线前在真机上确认（列入 `launch-checklist.md`）

- iPhone Safari、Android Chrome 各装一次；LINE / 微信中打开分享链接看到"在浏览器中打开"。
- iPhone 桌面 App 中：邮件链接（验证、邮件登录）在 Safari 打开而不是桌面 App，确认提示与流程可以接受；在桌面 App 中用 Google 登录能回到 App。
