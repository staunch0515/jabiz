# Q62 答题者页面的顶栏菜单与"我的学分"（2026-10-31）

需求方（2026-10-31）：

- "答题者的首页 topbar，除了 logo 外，其他 scan、theme 和 logout 合成一个下拉列表，放在最右边。"
- "目前的答题者底部菜单'钱包'，改成'我的学分'，相应的英语和日语也改。另外，这个页面的内容，在最上面显示当前余额和累积总额外，其他的功能也像 Account 页面处理，就是分多个页面。"

## 1. 顶栏

- 登录后的答题者 App（`quizbuks-web/app`，`App.tsx` 的 `Header`）：左边是名字（`Wordmark`），右边只有一个菜单按钮（`app-menu`，名为"菜单"）。
  菜单中依次是：扫码（Q52，答题与扫码页本身不显示）、外观（浅色 / 深色 / 跟随系统，平台的 `useAppearance`，文字用平台 `ui` 的 `appearance.*`）、退出登录。
- 未登录的页面（登录、注册、帮助、法律文本）的顶栏不变：外观切换与登录链接。

## 2. 我的学分

- 名称：en **My Kudos**，zh **我的学分**，ja **マイクドス**（底部菜单、页面标题、返回链接；App 中提到钱包的文字与答题者的三封邮件同样改为这个名字）。
  官网（`quizbuks-web/biz`）同样改称这个名字。地址仍是 `/wallet`（邮件与站内信里的链接不变）。商户后台的"钱包"是商户自己的，不改。
- `/wallet` 是菜单（与账户页 Q56 一样，组件 `pages/Menu.tsx` 共用）：最上面是当前余额（`available`）与累计获得（`totalEarned`），然后是
  - 学分：余额明细（`/wallet/balance`：等待商家、暂时保留、可转出、转出中）、按奖励方式（`/wallet/rewards`，Q58 的 `KudosOverview`；各方式的页面返回这里）、交易明细（`/wallet/history`）；
  - 收款：收款账户（`/wallet/payout`，显示状态）、提现到银行账户（`/wallet/bank`，开启时）。
- 不存在的部分回到菜单；底部菜单在 `/wallet/**` 全部标为"我的学分"。服务器不变（模板、流程照旧）。
