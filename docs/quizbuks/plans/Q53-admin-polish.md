## 2. Q53a 列表排序

- `hooks.ts` 的 `usePaged` 新增 `sorts`（列 id → 模板的 `list.sorts` 字段）：表头成为排序按钮，排序在服务端，新的排序回到第一页；
  未选择时照旧是模板（或读取函数）的缺省排序。`sortable(columns)` 给这些列加上访问器（DataTable 只让有访问器的列排序）。
- 每个列表读取函数多一个可选的 `sorts`，原样交给模板；原来写死的排序（审核队列、对账明细等）作为缺省。
- 用户页（自己的分页）同样可按用户名、显示名、注册时间排序。
- 模板的 `list.sorts` 补上页面显示的状态等列：发布、Quiz、作答（另有得分）、充值、转账、银行充值、提现、手工入账、运营商、结算、公告（另有标题）、运营商的审核（结论）。

| 页面 | 可排序的列 |
|---|---|
| 发布 | 名称、状态、期间（开始时间）、编辑时间 |
| Quiz | 标题、状态、题数、编辑时间；Quiz 详情：发布（名称、状态、编辑时间）、版本（版本号、保存时间） |
| 审核 | 发布（名称、等待时间）、商家申请（公司、提交时间） |
| 作答 | 开始时间、状态、得分 |
| 现金奖励 / 兑换 / 电子奖品 | 到期时间、金额、状态 |
| 充值 / 转账 / 提现 / 手工入账 | 时间、金额、状态；银行充值：时间、状态 |
| 对账 / 分录导出 | 计划时间 / 期间 |
| 运营商 / 运营商的审核 / 运营商的商家 / 获客 / 结算 / 公告 | 名称、状态、时间 / 决定时间、结论 / 公司 / 得分、发现与寄出时间 / 月份、应付、状态 / 标题、状态、发送时间 |
| 用户 | 用户名、显示名、注册时间 |

测试：`pages.test.tsx`（点击表头即按该字段向服务端排序，再点为倒序，从第一页开始；模板不能排序的列没有按钮）；`ext:check`；`platformCheck`（模板的排序字段）；`AdminOverviewIT`、`AdminReviewAccessIT`、`BroadcastIT`。

## 3. Q53b 补查询条件

- 新的 `moreFilters.tsx`：页面列出模板已声明（`list.filters`）而页面原来没有的条件，以平台的 `FilterBar`（"更多筛选"）显示：
  精确文本（编号、代码，可转大写）、字典或页面给出的选项、是否、金额范围、时间范围、日期范围；值转为模板的筛选（`eq`、`between`、`gte`、`lte`）。
- 原有的条件（状态、搜索、地址中的筛选）照旧；更多筛选与它们一起交给读取函数（各读取函数多一个可选的 `more`），并进入查询键：条件改变即从第一页读。
- 不改模板：所用的字段都是模板已声明的筛选字段。

| 对账 | 结果（无差异 / 有差异）、计划时间 |

| 作答 | 开始时间、提交时间 |
| 发布 | 开始时间、提交审核时间 |
| Quiz | 种类、状态、编辑时间 |
| 转账 | 金额 |

| 获客 | 发现时间、寄出时间 |

## 4. Q53c 视觉精致化（需求方 2026-10-31：后台保持平台的中性配色，不改平台）

管理后台与运营商后台**不用**商家后台的翠绿品牌色（需求方选择保持中性配色）：不加平台阶段，只在 QuizBuks 后台扩展内精致化，颜色只用平台主题的 token。

- **状态徽章**（`status.ts` 的 `statusTone`，`components.tsx` 的 `StatusBadge`）：按状态的含义上色，不论在哪个列表——完成、生效（绿，`success`）；
  等人处理（琥珀，`warning`）；拒绝、失败、下架、逾期（红，`destructive`）；结束、取消、草稿与未知的代码不上色（`outline`）。元素上留着代码（`data-status`）。
- **空状态**（`EmptyState`、`art.tsx`）：小插画（收件箱、完成、内容、金额、人员、搜索；内联 SVG、`aria-hidden`、只用中性 token 随亮暗变化）、一句说明、需要时一行提示，放在 `DataTable` 的 `empty`。
- **指标卡**（图标、标签、数值、可链接）随用到它的批次加入（运营商首页、财务概览）。
- **表格**：金额与计数右对齐、等宽数字（已有的保持；各批次补齐）。

| 批次 | 页面 |
|---|---|
| Q53c-1 | 共用部件；审核与内容（#383）：审核队列、发布、Quiz 与详情、发布与商户的审核、商户主页与商品 |
| Q53c-2 | 用户：用户、用户摘要、作答 |
| Q53c-3 | 财务：概览、充值、转账、提现、银行、手工入账、现金奖励、兑换、电子奖品、分录导出、对账、报表、投资人指标 |
| Q53c-4 | 运营商：首页（指标卡）、运营商、审核、商户、结算、获客、公告、账户 |

测试：`status.test.ts`（四种颜色、大小写、未知与空值）；`components.test.tsx`（徽章的颜色与代码、空状态的插画与文字、axe）；`pages.test.tsx` 的用户列表（商家状态与封禁的颜色、空列表的插画，Q53c-2）；各页面原有的测试（含无障碍检查）照旧通过；`ext:check`。
