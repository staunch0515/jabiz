## 需求方的决定（2026-10-30）

1. 第二项的"四种方式"是**奖励方式**（平台 Kudos、商户现金、到店兑换、电子奖品），不是支付方式：支付仍是同一种，不分开。
2. 维护页按**时区与浏览器语言**判断地区（不用 Cloudflare 或 IP 地理库）。
3. 语言开关：每个用户自己开关看哪些语言的 Quiz；**缺省只开界面语言**，不同语言的发布不显示在一起。
4. 音效开关**缺省开**。
5. 已有 Quiz 的语言不需商户确认（都是测试数据），迁移给一个缺省值即可。
6. 商户主页与商品首次发布需审核，之后修改直接生效、可事后下架（同 Quiz）。
7. Q59c（2026-10-30）：新商户**按申请时的语言**指派给该语言的运营商；运营商**只看到自己的商户**；已有商户**保持原样**（不按语言补指派）。

后台的视觉精致化（Q53c）排在这些之后。
