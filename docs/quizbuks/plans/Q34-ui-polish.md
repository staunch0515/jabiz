# Q34 界面精修（计划，2026-10-26 确认；Q34a、Q34b 已实现，待合并）

需求方（2026-10-26，1.2 上线前的测试意见）：首页要有答题者与商户的登录入口；答题者与商户的页面不够精致（圆角改平角、
弹出窗口加宽并居中、测试条一行）；答题者首页的问候 2 秒后消失、搜索只留一行（后接高级过滤）、默认不显示做过的题、
四种奖励改为搜索框前的图标下拉、卡片尽量显示成图片；商户后台的卡片标题与内容区分、菜单按业务分组、测验与发布列表改为卡片、
发布可以预览。需求方另指出：测验有标题和简介，材料也有标题、简介、正文，**哪项显示在答题者的哪里，后台不知道**，
所以无法确定答题者看到的样子；开始答题页也不够紧凑。

1.2 已冻结，只修 bug；这些是上线前的修正，需求方明确要求在 `1.2/quizbuks` 上做，完成后向前合并到 `1.3/quizbuks`。
不加迁移（1.2 不是最新的线）。

| D-Q34-7 | **搜索一行**：奖励方式图标下拉、搜索框、搜索按钮、高级过滤按钮。排序移进高级过滤；按钮上的数字计入排序与"显示已答过的" |

| D-Q34-13 | **预览**（Q34b）：发布与测验编辑页都有"预览"，以答题者的同一套组件渲染首页卡片、开始答题页与逐题页，只读、不计次数 |

### 开始答题页上每项内容的位置（D-Q34-11）

| 商户填的内容 | 答题者在哪里看到 | 怎么显示 |
|---|---|---|
| 发布名称 | 首页卡片、开始页大标题 | 完整 |
| 发布 / 测验封面 | 首页卡片、开始页顶部大图 | 铺满 |
| 测验标题 | 开始页大标题下一行 | 只在与发布名称不同时 |
| 测验简介 | "关于本测验"卡片 | 先显示 3 行，可展开 |
| 材料标题 | "答题前请阅读"列表 | 每份一行 |
| 材料简介 | 同一行标题下 | 一行，超出省略 |
| 材料正文、PDF、图片、音频 | 点开该行，全屏查看 | 不在开始页铺开 |
| 链接、站外视频 | 点该行直接打开站点（新标签页） | — |
| 可在页内播放的视频（YouTube、Vimeo） | 材料卡片最上面 | 直接可播放 |
| 奖品说明（到店 / 电子） | "你的奖励"卡片 | 完整 |
| 商户介绍 | 页底"关于商户" | 默认收起 |

开始页从上到下：大图（名称、测验标题、商户、奖励角标）→ 一块六项要点（题数、及格分 / 满分或"问卷"、时限、最高奖励或奖品价值、
支付方式、截止）→ 答题前请阅读 → 关于本测验 → 你的奖励（说明、奖品文字、分数档）→ 一行完成情况（明细收起）→ 关于商户（收起）→ 固定在底部的开始按钮。

## 3. 测试

- 商业网站：`phoneWindow` 的宽度、居中、小屏与第二块屏幕；每种语言的顶栏与页脚都有两个登录链接；e2e 登录链接打开的窗口与标签页。
- App 单元：问候 2 秒后收起、同一会话不再出现；搜索一行的顺序；默认 `includeAnswered=false`，开关打开后为真且计数；
  奖励下拉的选择与可访问名称；开始页的大图、六项要点、卡片标题底色、材料行与全屏面板、完成情况一行、收起的商户介绍；axe。
- 集成：`FeedIT.whatTheTakerAnsweredLeavesTheFeedUnlessAsked`（已提交、未通过的不列出，进行中的列出，开关打开全部列出，别人的作答不影响）；
  `theFeedReadsNoLargeTemporalTable` 不再把 `qb_attempt` 列为不读的表（只读调用者自己的行）。
- e2e：开始页的文章在全屏面板中显示 Markdown 并过 axe；商业网站的登录链接。

## 4. 风险

- 首页布局与开始页结构变化大，e2e 的选择器随之调整。
- `qb_attempt` 进入首页的查询：只按调用者的 `user_id` 读（唯一约束 `qb_attempt_once` 的前导列），每张卡至多一次索引探查。
- 1.2 上的改动须向前合并到 1.3；1.3 的 S0 主要改后端，冲突预计不多。
