## 1. 需求方的不满（2026-11-05）

- 菜单越来越多：现在 6 组 19 项（`sponsor/src/App.tsx` 的 `groups`），每加一个功能就多一项。
- 页面框架、页面布局不统一。
- **"新建"按钮在最右边，屏幕大时很难找到**：`@jabiz/ui` 的 `PageHeader` 把 `actions` 放在标题行的另一端（`justify-between`），内容又是满屏宽。
- 商户资料的二级菜单（Q79 的 `ProfileLayout`）：大屏上是"侧栏 + 二级菜单 + 正文 + 右侧说明"四列，正文被挤窄；小屏上是要横着滑的一行。

## 2. 菜单：按"地方"分，8 个区域

每个菜单项是一个区域，区域里的页面用标题下的一排**页内标签**切换。**以后加功能只加标签，不加菜单项**（实施时写进 `backend/quizbuks/CLAUDE.md` 第 5 节，取代 Q79"新的商户设置页加为一个节"的写法）。

| 菜单 | 标签（现在的页面） |
|---|---|
| 首页 | 仪表盘与"待我处理"（待确认的领取、未读对话、预算不足、审核中、资料缺项；每条直接带到那一页） |
| Quiz | 模版列表、编辑 |
| 发布 | 列表 / 结构图（现在的"树"，Q85、Q90）/ 统计（现在设置下的"统计"）；发布详情另有自己的标签（概况、题目与版本、受众、奖励、统计、分享与二维码） |
| 奖品与兑换 | 到店兑换 / 现金奖励 / 电子奖品 |
| 客户与消息 | 对话 / 通知与公告（现在的"消息中心"）/ 客户（结构图上的人） |
| 合作权益 | 目录 / 我的权益 / 洽谈 / 采购单。**只有持有 `BENEFIT_PROVIDER` 或 `BENEFIT_SPONSOR` 的发起方才显示** |
| 资金 | 交易 / 钱包 / 账单与平台费（Q101、Q105） |
| 商户中心 | 概况 / 基本信息 / 公开主页 / 商品 / 店员 / 认证（现在内容组下的"认证"）/ 邮件服务器 |

- 右上角头像菜单：账户与安全、外观、语言、帮助、退出（不再占左侧菜单）。
- 大屏：侧栏可收成只有图标的窄条（记在本机）。
- 手机：底部 首页 / 发布 / 兑换 / 消息 / 更多（"更多"打开全部菜单）；需求方对这 4 个的选择尚未确认。
- 旧地址全部保留转向（书签、邮件中的链接、PWA 的起始页），照 Q79 的 `LEGACY_PROFILE_PATHS` 的做法。

## 3. 页面框架

- **全局"＋ 新建"**：侧栏最上方，任何页面都能用（新建 Quiz、新建发布、发通知、导入发布设置）。
- **页头**：标题，**主按钮紧跟在标题旁**；说明一行；页内标签。手机上主按钮改为右下角的浮动按钮（在底部菜单之上）。
- **内容最大宽度**约 1360 像素居中（表单页约 960），宽屏上按钮不会离标题太远。
- 三种页面模板：
  - **列表页**：页头 → 工具栏（搜索、状态筛选的小标签、卡片 / 表格切换）→ 卡片或表格（Q34b、Q80 不变）。
  - **详情页**：左边内容，右边固定的"状态与下一步"栏（步骤、主要操作）；手机上这一栏在内容之前。
  - **表单页**：单栏、限宽，底部固定的"放弃 / 保存"条（显示是否有未保存的修改）。
- 商户中心的"概况"：完成度与每节一张卡片（完成或待填写、还差什么），二级菜单里的说明文字移到卡片上；资料包的导出与导入（Q100）在概况的页头。

## 4. 平台先行

侧栏的收起、页内标签、全局新建按钮、页头主按钮的位置、内容最大宽度、手机底部菜单与浮动按钮都在平台的 `@jabiz/ui`（`AppShell`、`ShellNav`、`PageHeader`）中，按根 CLAUDE.md 第 8 节先在 `1.3/platform` 上加（带平台自己的测试与示范，亮暗两种外观过 axe），再合并到 `1.3/quizbuks`。与 Q107 同样需要在平台分支上工作的许可。

## 5. 时机与顺序（需求方 2026-11-05 同意）

1. 2026-11-06 额度重置后，先定功能的大调整；8 个区域的分法随之微调（新功能落在哪个区域）。
2. **先做框架**（§2 的菜单、§3 的框架与模板），之后所有新功能直接按新样式写。
3. **页面随功能一起改**：功能调整碰到的页面，在那次修改里套上新模板；没碰到的页面最后集中迁移一次。
4. 粗估：平台框架 3–4 天，发起方后台 4–5 天（菜单、模板、各区域改成标签），e2e 随之改。

需求方 2026-11-05 要看同样的思路用在答题者页面上的效果。原型：https://claude.ai/artifact/E1Ycg8vWyEGb7xd6TVZPZD（待需求方看后决定）。答题者 App 已基本满意，原型只做与此一致的小调整：
