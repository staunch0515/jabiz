# Q17 管理员看全量的问卷、发布与答题

需求方 2026-10-23："admin审核完Quiz后就没有再看到。在 admin 侧需要看到全部的 quiz，publication，和答题的情况。"
确认（2026-10-23）："看全量问卷"和"看全量发布活动"都要做；顺序为 Q17 → 平台 16zc → 同步 → Q18（银行转账设置页、手工加币）。

## 1. 问题

审核页（`/qb/reviews`）只列待审的发布（`status = PENDING_REVIEW`），决定后它就从队列中消失；后台没有列出全部 Quiz 的页面，
也没有列出每个状态的发布的页面。答题情况已有 `/qb/attempts`（Q14），但没有从发布进入的路径。

## 2. 做了什么

| 部分 | 内容 |
|---|---|
| 模板 `qb.admin.quizzes` | 全部商家的 Quiz（含已删除的，`removed` 标出），按标题搜索（`q`，原样匹配），按 `quizId`、`ownerId`、`kind`、`status`、`removed`、`editedAt` 筛选；每个 Quiz 的发布数（含草稿）。权限 `qb.admin.quiz.read`（内容管理员） |
| 模板 `qb.admin.quiz-versions` | 一个 Quiz 的版本（最新在前），不含内容：内容带正确答案，只在要求时按版本读取。权限 `qb.admin.quiz.read` |
| 模板 `qb.admin.publications` | 增加结果与筛选 `quizId`（其余不变，仍不含资金） |
| 后台 `/qb/quizzes` | 列表：标题（链到详情）、商家（链到用户汇总）、类型、状态（"版本后有修改"）、版本、题数、发布数（链到该 Quiz 的发布）、最后修改；"显示已删除的 Quiz"；地址带 `q`、`sponsor`、`removed` |
| 后台 `/qb/quizzes/:quizId` | 只读：概要；该 Quiz 的全部发布（每个状态，链到发布页与答题记录）；版本表，"显示内容"时才读取该版本的冻结内容（`VersionPreview`，含正确答案）；草稿（商家当前编辑的内容，从内容的默认数据视图读出，按各部分的顺序编号，用同一个预览显示）。已删除的 Quiz 没有草稿，版本仍在 |
| 后台 `/qb/publications` | 每个状态的全部发布，最近修改的在前：名称（链到发布页）、Quiz（有 `qb.admin.quiz.read` 时链到详情）、商家、状态（被退回的草稿标"已退回"）、期间、参与 / 完成 / 获奖人数、答题记录（链到 `/qb/attempts?publication=`）；按名称搜索，按状态、商家、Quiz 筛选（地址带 `q`、`status`、`sponsor`、`quiz`）。权限 `qb.admin.publication.read`（内容与财务管理员） |
| 发布页 | 从列表或 Quiz 打开时"返回"回到来处（路由状态，不经地址）；页头增加"打开 Quiz"与"答题记录" |
| 用户汇总 | 商家一栏增加"Quiz"与"发布"，链到按该商家筛选的列表 |

全部只读，没有迁移，没有新流程与权限。

## 3. 测试

- `AdminOverviewIT`：两位商家的 Quiz 按标题搜到、已删除的标出、按商家与 `removed` 筛选；版本最新在前且不含内容；草稿的各部分可按 `quizId` 读出、Quiz 本身按主键读出；
  一个 Quiz 的草稿、已排期与被退回的发布都按 `quizId` 列出（被退回的带原因），按状态筛选；财务读发布不读 Quiz 与版本；商家三个模板都 403。
- 扩展 Vitest `overview.test.tsx`：列表的筛选与链接、显示已删除、搜索与清除；详情的概要、发布、按顺序的草稿与正确答案、按要求才读版本内容（按钮按下后不重建、保持焦点）、
  已删除没有草稿、没有发布权限时不显示发布、不存在；发布列表的状态与"已退回"、答题链接、按地址筛选、财务看不到 Quiz 链接、返回来处；草稿按页读完（250 个选项）。
- e2e：`review.spec.ts` 退回后在发布列表中仍可见并标"已退回"，打开后返回列表；`a11y.spec.ts` 三个新页面在亮暗两种外观下过 axe。

## 4. 风险

- 草稿最多约 900 行（100 题 × 6 个选项与资料图片），按页读取：只在打开详情时读一次。
- 版本内容含正确答案：与审核页相同的权限（`qb.admin.quiz.read`），只在点"显示内容"时读取。
