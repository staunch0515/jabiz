# Q15 发布的分享链接：只凭邮箱开始答题

需求方 2026-10-23："给某个发布提供一个链接就可以开始答题的。点击链接后，在答题开始页面就只要输入一个电子邮件信息，
如果是已经注册的用户就直接进入答题开始环节，如果不是就提示打开信箱验证链接，验证通过后就转入答题开始页面。"
确认（2026-10-23）：邮件链接或密码；新用户只填国家与条款；分享页显示 Quiz 概要。平台部分是 16zb（决策 D54），先在 `1.2/platform` 完成并同步。

## 1. 为什么已注册的用户也要点邮件中的链接

只凭输入的邮箱就进入，知道别人邮箱的人就能以他的名义答题（每个发布每人只有一次），页面也不能透露某个邮箱是否已注册。
所以：已在本设备登录的直接进入；其他人输入邮箱后收到一次性链接（平台 D54），已有账号即登录，新地址即开设已验证的账号，
然后都回到 `/p/<发布>`。仍可改用密码登录。

## 2. 做了什么

| 部分 | 内容 |
|---|---|
| 入口 | App 入口开启 `email-link`（`QB_APP_EMAIL_LINK`，缺省 `true`）。新地址开户还要入口开放注册（`QB_APP_SELF_REGISTRATION`）；关掉注册时只有已有账号能收到链接 |
| 公开视图 | `urn:jabiz:dataset:public:QbPublicationCard`：固定范围 `status = LIVE`，白名单 `publicationId`、`sponsorId`（只用于关联商家，模板不返回）、`name`、`quizTitle`、`kind`、`startAt`、`endAt`、`timeLimitSec`、`questionCount`、`fullScore`、`passScore`、`maxReward`。`urn:jabiz:dataset:public:QbSponsor`：固定范围已批准，白名单 `userId`（同上）、`company` |
| 公开模板 `qb.public.publication` | 参数发布与时点；只在此刻进行中（`startAt <= at < endAt`）时返回一行：上述字段与商家公司名。地区、预算、奖励档、商家的人名与编号都不在其中。封面不显示：卡片上的封面只是文件键（文本），不是文件字段，公开时不能推导出文件 |
| App `/p/<id>`（未登录） | `SharePage`：概要（题数、时限、最高奖励、截止时间、商家），`EmailLinkForm`（`to = /p/<id>`），"改用密码登录"（`/login?next=/p/<id>`）。不开放时说明"目前未开放" |
| 邮件链接页 | `/auth/email-link`（平台的 `MailLinkPage`），点击后登录并回到 `/p/<id>`；第二因素照常 |
| 首次进入 | 没有国家的答题人从 `/p/<id>` 进入时先到 `/welcome` 的简短一步：只有国家（与条款）；名字取注册名、否则邮箱 @ 之前的部分，货币取国家的，之后可在账户中修改；保存后回到 `/p/<id>`（本标签页的 `sessionStorage` 记住目标） |
| 登录页 | `/login?next=<路径>`：登录后回到该路径（只认本站以 `/` 开头的路径） |
| 商家后台 | 进行中与已排期的发布显示"复制分享链接"：`<站点>/p/<发布>`（App 在站点根），复制失败时显示链接 |

没有迁移。

## 3. 测试

- `ShareLinkIT`：公开模板只返回白名单字段与公司名，暂停、结束、未知时没有行；App 入口的邮件链接带 `to=/p/<id>`，打开后是已验证的 `QB_TAKER`。
- App Vitest `share/share.test.tsx`：未登录的分享页、请求链接的参数、未开放、邮件链接页、`/login?next=`、新答题人的简短一步并回到发布。
- 商家 Vitest：进行中的发布复制链接，暂停的不显示。
- e2e `share.spec.ts`：分享页 → 输入邮箱 → Mailpit 中的链接 → 简短一步 → 回到发布，可以开始。

## 4. 风险

- 邮件延迟：页面说明"可能需要几分钟"。
- 邮件扫描器打开链接：不改变任何东西，使用链接要点击。
- 批量开户：平台的限流（按地址与邮箱）、每个发布每人一次、奖励的保留期。
- 转发的链接（平台 D54 的剩余风险）：把自己的链接发给别人，对方会进入发送者的账号。
