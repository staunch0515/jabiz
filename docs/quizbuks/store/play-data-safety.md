# Google Play 数据安全表（Q49d-1）

由需求方在 Play Console → 应用内容 → 数据安全 中填写；本页逐格写明勾什么、依据隐私政策（`docs/quizbuks/legal/privacy-policy.ja.md`，下称"政策"）的哪一条。
TWA 中运行的是 `/taker/` 网页，Google 要求如实申报**网页在 App 中收集的数据**，所以按 App（答题者）实际收集的写；商家后台的数据（商家资料、充值、上传的文件）不属于这个 App，不申报。

**政策或代码改了就重新核对本页**（`legal/README.md`"代码改动时"）；表单改了也同步本页。

## 1. 总问题

| 问题 | 答 | 依据 |
|---|---|---|
| 应用是否收集或分享所需的任何用户数据类型？ | 是 | 政策第2条 |
| 所有用户数据在传输过程中都加密？ | 是 | HTTPS（政策第9条） |
| 用户能否申请删除数据？ | 是 | 政策第10条；删除账号的网址见 §4 |
| 账号创建方式 | 用户名与密码、OAuth（Google 等）；以及"其他"：邮件中的一次性登录链接 | 政策第2条第1、2项 |

## 2. 收集的数据

"必需"指不提供就不能用 App；"可选"指用户可以不填。用途的名称与 Play 表单一致。没有一项用于广告或营销，也没有"暂时处理"（都会保存）。

| Play 的类别 → 类型 | 收集 | 分享 | 必需 / 可选 | 用途 | App 中的数据（政策） |
|---|---|---|---|---|---|
| 个人信息 → 姓名 | 是 | 是（§3） | 必需 | 应用功能、账号管理 | 显示名（2.1） |
| 个人信息 → 电子邮件地址 | 是 | 否 | 必需 | 应用功能、账号管理、开发者通信、防欺诈与安全 | 邮箱（2.1、2.2） |
| 个人信息 → 用户 ID | 是 | 否 | 必需 | 应用功能、账号管理、防欺诈与安全 | 本服务的用户编号；Google 等外部账号的标识（2.2）；商家看到的是按商家不同的化名编号（第4条），不是用户 ID |
| 个人信息 → 其他信息 | 是 | 否 | 可选 | 应用功能 | 国家或地区、城市；"关于我"的性别、出生年、职业、兴趣（2.1） |
| 财务信息 → 其他财务信息 | 是 | 否 | 必需 | 应用功能、防欺诈与安全 | 获得的奖品（门店领取）与领取记录、争议（2.1） |
| 应用活动 → 应用互动 | 是 | 是（§3） | 必需 | 应用功能、分析、防欺诈与安全 | 答题的答案、开始与提交时间、分数、合格与否；收件箱的已读与点击（2.1）；操作记录（2.3）；举报测验的原因与说明（Q49a，只给审核者，不给商家）。"分析"指不识别个人的统计（第3条第7项） |

**推广期**（`operations.md`"阶段一"：只有门店领取的奖品，`qb.transfer.enabled` 与 `qb.withdrawal.bank.enabled` 为 `false`，Q49d D-Q49d-6）：App 不显示收款账户的填写，
所以**不申报"财务信息 → 用户付款信息"**。开始现金奖励或提现时（开关之一改为 `true`）**先**在 Console 中补报：用户付款信息，收集、不分享、可选，用途"应用功能"，依据政策 2.1 的收款账户。

**不申报的类型**（都不收集）：位置（精确、大致）、电话号码、地址、种族与民族、政治与宗教、性取向、购买记录（答题者不购买）、信用评分、健康与健身、消息（短信、邮件、应用内消息：收件箱只有运营方的通知，用户不能发送）、照片与视频、音频、文件与文档（答题者不上传）、日历、通讯录、已安装的应用、网络浏览记录、应用内搜索记录（不保存）、崩溃日志与诊断（没有第三方分析）、设备或其他 ID（不读取设备标识与广告 ID）。

关于 IP 地址与浏览器类型（2.3）：只为登录安全记在登录记录与会话中，不用来推定位置（政策写明），不是设备标识。Google 的说明是 IP 按它被用于的数据类型申报；没有用于位置或识别设备，因此不另申报。审核若要求，就在"设备或其他 ID"下申报为"防欺诈与安全"。

关于相机（Q52）：App 内的"扫一扫"只在本机读二维码，画面不保存、不上传（政策 2.3 末尾），不是收集的数据（"照片与视频"不申报）；摄像头的使用由 Chrome 按网站询问权限，Android 外壳不声明相机权限。

关于 Stripe：领取现金奖励的答题者在 **Stripe 自己的页面**上填写身份与银行信息（政策第5条），本服务不经手；Stripe 是服务提供方，按 Google 的定义不算"分享"。

## 3. "分享"

Google 的定义：转给第三方。服务提供方（Stripe、邮件、服务器、视频播放器）代我们处理，不算分享。
答题者回答商家的问卷时，**该商家**看到答题者的显示名、分数、奖励与佣金（政策第4条）：商家是第三方，所以"姓名"与"应用互动"申报为分享，用途"应用功能"。
商家看不到邮箱、用户编号与每题的答案；"关于我"不给商家（政策第4条）。

## 4. 删除账号

- 表单的"删除账号的网址"：填 `https://quizbuks.com/taker/delete-account`（Q71；生产须先以 `QB_APP_ACCOUNT_DELETION=true` 开启，`DEPLOY.md` §1a）。
- **在那之前**（封闭测试开始时）：填隐私政策的地址 `https://quizbuks.com/taker/legal/privacy`（第10条写明以注册邮箱申请删除），并在"可否申请删除部分数据"选"否"。Google 不接受时，封闭测试的发布等 Q49a。
- 删除后保留的记录：政策第8条（交易与防止滥用的记录；收据与会计记录 10 年）。表单中说明"部分数据因法律义务保留"。
