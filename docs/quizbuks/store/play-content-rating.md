# Google Play 内容分级与目标受众（Q49d-1）

由需求方在 Play Console → 应用内容 中填写。本页给出每题的答案与理由；问卷（IARC）的措辞以 Console 中显示的为准，意思不同时按理由作答。

## 1. 内容分级问卷（IARC）

- **类别**：所有其他应用类型（不是游戏，不是参考、新闻或教育类）。
- **联系邮箱**：`quizbuks@gmail.com`（`qb.support.email`）。

| 问题 | 答 | 理由 |
|---|---|---|
| 暴力、血腥 | 否 | 问卷由商家撰写，管理员审核后发布 |
| 性内容、裸露 | 否 | 同上 |
| 粗俗语言 | 否 | 同上 |
| 受管制物质（毒品、酒精、烟草） | 否 | 不允许以酒类、烟草或毒品为题材或奖品的问卷（2026-10-28 需求方决定），发布前审核时拒绝 |
| 赌博：真钱赌博 | 否 | 答题不需要付钱，奖励按分数给出，不是抽签或押注 |
| 赌博：模拟赌博 | 否 | 同上 |
| 用户之间可以交流或交换内容 | 否 | 答题者之间、答题者与商家之间都没有消息、评论或聊天；商家的问卷经审核后才发布 |
| 分享用户的位置 | 否 | 不收集位置 |
| 应用内购买数字商品 | 否 | App 中没有任何购买（商家的充值不在 App 中） |
| 是否为网页浏览器或搜索引擎 | 否 | 只打开本服务的 `/taker/` |

**酒类**（2026-10-28 需求方决定）：不允许。发布一律在发布前审核（`qb.review.publication.auto = false`，推广期同样，`operations.md`"阶段一"），审核员拒绝以酒类、烟草或毒品为题材或奖品的问卷。
以后若允许酒类问卷，先把这一题改答"是"并重新分级，再改审核规则。

预计结果：IARC 3+ / PEGI 3 / USK 0 / ESRB Everyone 一级；Play 会附加"用户互动"等说明时照实保留。

## 2. 目标受众与内容（2026-10-28 决定：18 岁以上）

| 问题 | 答 |
|---|---|
| 目标年龄组 | 只选 **18 岁及以上** |
| 应用是否可能吸引儿童 | 否（不使用卡通角色、儿童题材；问卷对象为成人） |
| 商店信息 | 说明中写明面向 18 岁以上（`play-listing.*.md`"使用须知"） |

因此不适用"家庭"政策，也不加入"教师认可"计划。隐私政策第11条（未成年人须经监护人同意）与此不冲突。

## 3. 其他声明（应用内容页）

| 声明 | 答 | 理由 |
|---|---|---|
| 广告 | 不含广告 | 没有广告 SDK，也不显示广告（政策 2.3） |
| 应用访问权限 | 部分功能受限，提供登录信息 | 见 `play-review.md` |
| 政府应用 | 否 | |
| 金融功能 | 不提供金融功能 | 推广期只有门店领取的奖品，没有现金奖励、转账与提现（2026-10-28 需求方决定） |
| 健康应用 | 否 | |
| 新闻应用 | 否 | |

**以后**开始现金奖励或提现（`qb.transfer.enabled`、`qb.withdrawal.bank.enabled`）之前，重新评估这一项（可能属于"支付或汇款"），并同时改数据安全表（`play-data-safety.md` §2）与商店说明（`play-listing.*.md`）。
