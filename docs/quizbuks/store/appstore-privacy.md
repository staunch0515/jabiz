# App Store 的 App 隐私（隐私标签）（Q49d-2）

由需求方在 App Store Connect →（本 App）→ App 隐私 中填写；本页逐项写明选什么、依据隐私政策（`docs/quizbuks/legal/privacy-policy.ja.md`，下称"政策"）的哪一条。
iOS App 是打开 `/taker/` 的外壳，Apple 要求申报**App 中收集的全部数据**（网页收集的也算），所以与 Google Play 的数据安全表（`play-data-safety.md`）按同一份政策写，两边一起改。

**政策、App 收集的数据或推广期的开关改了就重新核对本页与 `play-data-safety.md`**。

## 1. 总问题

| 问题 | 答 | 依据 |
|---|---|---|
| 你或你的第三方合作伙伴是否从此 App 收集数据？ | 是 | 政策第2条 |
| 隐私政策网址 | `https://quizbuks.com/taker/legal/privacy` | 需求方发布后（`legal/README.md`） |
| 用户隐私选择网址（可选） | 留空 | 收件偏好与"关于我"在 App 中修改（政策第10条） |

## 2. 收集的数据类型

每一项都是"**与用户关联**"、"**不用于追踪**"（没有广告、没有第三方分析，不与其他公司的数据合并：政策 2.3）。用途的名称与 App Store Connect 一致。

| Apple 的类别 → 类型 | 用途 | App 中的数据（政策） |
|---|---|---|
| 联系信息 → 姓名 | App 功能 | 显示名（2.1）；商家看到答题者的显示名（第4条） |
| 联系信息 → 电子邮件地址 | App 功能、开发者的广告或营销以外的通讯（选"App 功能"即可） | 邮箱（2.1、2.2）：登录、验证与通知邮件 |
| 标识符 → 用户 ID | App 功能 | 本服务的用户编号；Google 等外部账号的标识（2.2） |
| 使用数据 → 产品交互 | App 功能、分析 | 答题的答案、时间、分数；收件箱的已读与点击；操作记录（2.1、2.3）。"分析"指不识别个人的统计（第3条第7项） |
| 其他数据 → 其他数据类型 | App 功能、产品个性化 | 国家或地区、城市；"关于我"的性别、出生年、职业、兴趣（2.1）：按地区与条件显示问卷（第3条第2、3项） |

**不申报的类型**（都不收集）：健康与健身、财务信息（推广期没有收款账户与提现，见下）、位置（精确、粗略：不收集也不由 IP 推定，政策 2.3）、敏感信息、通讯录、
用户内容（答题者不上传照片、视频、音频或文件，也不能发送消息；答案按"产品交互"申报）、浏览历史、搜索历史、诊断（没有崩溃日志与第三方分析）、购买（答题者不购买）。

- **推广期**（`operations.md`"阶段一"，D-Q49d-6）：不申报"财务信息"。开始现金奖励或提现之前，**先**加"财务信息 → 付款信息"（收款账户，App 功能，与用户关联），与 `play-data-safety.md` §2 一起改。
- **推送**（平台 17k 合入后）：设备令牌按 Apple 的定义属于"标识符 → 设备 ID"，用途"App 功能"，与 Q49c-2 一起补上。
- **IP 地址与浏览器类型**（政策 2.3）：只为登录安全记录，不用于推定位置，Apple 没有单独的类型；审核若要求，在"标识符 → 设备 ID"下申报为"App 功能"。
- **相机**（Q52）：App 内的"扫一扫"只在本机读二维码，画面不保存、不上传（政策 2.3 末尾），不是收集的数据，不申报；iOS 外壳以 `NSCameraUsageDescription` 说明用途。
- **Stripe**：领取现金奖励时答题者在 Stripe 自己的页面上提交的信息不经本服务（政策第5条）；推广期不出现。
