# S3b：套餐页、用量提示与店面的 "Powered by QuizBuks"（计划已确认 2026-10-27，"默认建议"）

依据：`S3-billing.md` §4（已确认的 S3 计划）。后端是 S3a（PR #284），S3b 只做界面，原则上不改后端（需要时先停下来说明）。线 1.3，工作分支 `1.3/quizbuks-S3b-ui`，从 S3a 合并后的 `1.3/quizbuks` 拉出。

## 1. 内嵌后台（`quizbuks-web/shopify`）

| # | 内容 |
|---|---|
| P-1 | 第三个标签**套餐与用量**（概况、答题活动之后）。数据来自 `QBS_PLAN_GET`，以 TanStack Query 的一个键共用：概况页的提示（P-4）与本页读同一份，不重复请求 |
| P-2 | **本页显示**：<br>- 当前套餐（免费 / 入门 / 成长 / 专业），Shopify 的测试扣款显示"测试"标记；<br>- 试用中时："试用到 <日期>"；<br>- 降级后保留期内："<日期> 起改为 <套餐>"（`nextPlan` / `planUntil`）；<br>- 本周期起止；<br>- 已完成 / 上限，加进度条与百分比；<br>- Shopify 的套餐名对不上任何一个时（`unknownPlan`），提示"按免费套餐计，请联系我们"；<br>- 店铺需要重新连接时（`RECONNECT`），提示套餐暂时读不到、显示的是上次读到的，并给出概况页的"重新连接"入口；<br>- "上次从 Shopify 读取：<时间>" |
| P-3 | **操作**：<br>- "选择套餐"：在 Shopify 后台的顶层打开 Shopify 托管的套餐页（`window.open(pricingUrl, '_top')`，地址由服务端给出），不在内嵌框里打开；<br>- "从 Shopify 刷新"：`QBS_PLAN_GET` 带 `refresh: true`；<br>- 从 Shopify 的套餐页回到应用时（Shopify 带回 `charge_id` 参数），自动以 `refresh: true` 读一次（参数名在联调时核实；平时靠 S3a 的 webhook 即时更新） |
| P-4 | **概况页提示**（所有成员可见）：<br>- 用到 80%：提示"本周期已用 X%，到上限后店面不再显示答题"，带"查看套餐"按钮（切到套餐标签）；<br>- 用到 100%：醒目的提示"本周期的答题次数已用完，店面已停止显示答题，<周期截止> 恢复，或升级套餐"，带"选择套餐"按钮 |
| P-5 | 三种语言的文字（`messages.ts`，沿用键齐全的测试）。日期按界面语言格式化 |

## 3. 测试与 CI

- 内嵌后台（Vitest，fetch 用桩）覆盖：
  - 免费套餐、付费且试用中、测试扣款、降级保留期、不认识的套餐名、需要重新连接；
  - 80% 与 100% 的概况提示，以及不到 80% 时不提示；
  - "选择套餐"以 `_top` 打开服务端给的地址（`window.open` 用桩）；
  - "从 Shopify 刷新"与带回 `charge_id` 时都发 `refresh: true`；
  - `expectAccessible`；`pnpm app:check`。
- 店面组件：`badge` 为真时结果页有 "Powered by QuizBuks"，为假时没有；axe 照旧。
- 不写 Playwright 端到端：理由同 S2b（App Bridge 与真实店面），套餐页的跳转放进联调清单。
- CI：沿用 `quizbuks.yml` 现有的 shopify 与 storefront 步骤，不另加。

## 6. 实施说明（与计划不同或计划未写的）

| # | 内容 |
|---|---|
| I-1 | 进度条是原生 `<progress>`（Q-S3b-1 的确认），只用主题 token 着色；上限为 0 时画成用满，与"100%"一致 |
| I-2 | 周期的日期按 **UTC** 显示，并注明 "(UTC)"：周期从一个时刻到另一个时刻（不含），末日显示为截止的前一天；"恢复于"显示截止当天 |
| I-3 | 从套餐页回来时的 `charge_id` 只用一次：读到后从地址中去掉（Shopify 的其他参数保留），以后再打开照常读，不每次都去问 Shopify |
| I-4 | 套餐的读取若发现店铺需要重新连接（Shopify 拒绝了令牌），概况页随之显示"需要重新连接"；概况页重新连接或检查之后，套餐也随之重读。套餐页的"需要重新连接"提示带"前往概况"按钮 |
| I-5 | 套餐的读取按登录的店员区分（一个标签页可能换到另一家店的店员） |
| I-6 | 店面的 "Powered by QuizBuks" 不降低透明度（保持主题文字色的对比度），结果页带它时也做 axe 检查 |

**测试**：内嵌后台 `PlanPage.test.tsx`（8 例）：免费套餐与 UTC 周期、付费试用与测试扣款与降级、不认识的套餐名与需要重新连接（带前往概况）、刷新失败的提示、上限为 0、选择套餐以 `_top` 打开与刷新、从套餐页回来只读一次、80% 与 100% 的提示；`App.test.tsx` 照旧通过。店面 `quiz.test.ts` 加 1 例：免费套餐结果页有 "Powered by QuizBuks"（axe），付费没有，入口与答题中都没有。
