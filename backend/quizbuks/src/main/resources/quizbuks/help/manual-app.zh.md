学者使用 App 的方法。路径是 App 中的页面（以 /taker 开头）。

## 开始使用

- 登录和注册在同一个页面（/taker/login）：输入邮箱，点"继续"。我们会给这个邮箱寄一封链接，请在本设备上打开；新邮箱在那里填写名字即完成注册。同一步可以"改用密码"（"忘记密码？"可以设置密码），页面上也可以用 Google、LINE、Facebook 或"用通行密钥登录"。在上次用密码登录的设备上，点"继续"会直接请你输入密码。
- 填写个人资料（/taker/welcome）：名字和所在的国家或地区。Quiz 按国家和地区提供。
- App 底部有四个图标："首页"（/taker/）、"搜索"（/taker/search）、"已答"（/taker/history）和"通知"（/taker/inbox）。右下的圆形按钮是"扫一扫"（/taker/scan）。点左上的头像打开侧边菜单："我的主页"（/taker/account）、学分、奖品、证书、知识结构图、推荐朋友、设置、帮助和退出登录。

## 找 Quiz（首页，/taker/）

- 首页上每个 Quiz 是一条帖子：发起方的头像、名字和发布了多久，下面是 Quiz 的名称和简介的开头、图片或视频，最后一行是奖励、已答人数、时限和分享按钮。点发起方的头像或名字进入发起方的主页；点名称、文字或图片打开 Quiz。
- 首页列出你可以回答的 Quiz。可以搜索、排序（最新、奖励、完成人数等）和筛选（发起方、发起方所在国家或地区、奖励、完成人数）。
- 已回答的 Quiz 默认不显示；打开"显示我回答过的 Quiz"即可看到。
- 全屏的视频模式：点首页帖子上的视频或"短视频"一排中的一个，即全屏观看（黑底，上下滑换视频，没有视频的 Quiz 跳过）。视频下方有"详情"（开始页）与"开始答题"（直接开始；要先看完的视频会显示还差几秒）。
- 喜欢的主题：在"设置 → 关于我"（/taker/account/details）选择主题，打开"只看喜欢的主题"后，首页和短视频只显示这些主题的 Quiz。
- Quiz 的语言：在"设置 → App 设置"（/taker/account/preferences）选择；不选时跟随 App 的语言。
- 屏蔽：Quiz 的"…"菜单中有"不感兴趣"，以及屏蔽这个 Quiz 的所有轮次、屏蔽发起方或屏蔽视频提供者。屏蔽的内容不再显示，也不能回答。可在"设置 → App 设置"中解除。
- 有些 Quiz 只面向资料符合发起方条件的人；在"关于我"中填写更多信息，可能就能回答。发起方看不到你在"关于我"中的回答。
- 挂在知识结构图上的 Quiz，要点亮它需要的节点后才会出现。含有在你当前所在地无法播放的视频（例如在中国大陆的 YouTube）的 Quiz，会显示"该内容在你所在的地区不可用"。

## 答题（/taker/p/…）

- Quiz 页面显示发起方（点"主页"去发起方的主页）、名称和介绍、视频或封面、多少人已答和截止日期，以及一行最高奖励、题数、时限和合格线。下面有两个标签：资料，以及规则（奖励在规则之下）。点"开始答题"后开始计时。每人只有一次机会。
- 有些 Quiz 要求先看完视频。首次上线时没有报名费；报名费开放后，有些 Quiz 需要报名费，从可转出的学分中支付，无论结果如何都不退还。
- 答案会随时保存。答完后提交；时间到时，已保存的答案会自动提交。
- 调查问卷没有正确答案：回答全部问题才能得到奖励。
- 结果页显示得分、合格分、是否通过、奖励以及每道题的情况。
- AI 问题解答不能帮你回答 Quiz 的题目。

## 奖励

每个 Quiz 都写明奖励的支付方式。首次上线时学分只显示、还不能使用：发起方的奖励是现金、到店领取的奖品和电子奖品，不发学分。

- 学分（学分开放后）：通过后立即进入"我的学分"。发起方预算用完时，奖励为"待支付"，发起方充值后支付。
- 发起方的现金：通过后你会得到一个码。发起方付款时出示该码，然后在 App 中确认已收到，或反馈问题。没有按时确认或反馈之前，不能开始新的 Quiz。
- 到店领取的奖品：在发起方的店里，点右下的圆形按钮"扫一扫"（/taker/scan），扫描对方屏幕或海报上的码，再点你要领取的奖品。请在期限内领取。
- 电子奖品：码、券或链接会出现在 App 中。点"查看奖品"，确认可以使用，或反馈问题。
- "已答"（/taker/history）列出你回答过的每个 Quiz 及其结果和奖励；还要领取或确认的奖品显示在那一行下面的框里。标签"待领奖"（/taker/history/prizes）列出等你领取的奖品，"未完成"（/taker/history/unfinished）列出还没答完的 Quiz。

## 我的学分（/taker/wallet）

- 首次上线时学分只显示、还不能使用："我的"最上面的学分显示 0 并标着"即将开放"，学分不能转出或提现。以下是学分开放后的用法。
- 显示你的学分、等待发起方支付的、暂时保留的和正在转出的。新得到的学分要保留几天后才能转出。
- （学分开放后）收款方式：Stripe（每天把学分转到你的 Stripe 账户），或日本的银行账户（/taker/wallet/bank：每次由你申请提现，经人工审核，每次提现收取手续费）。更改银行账户后，要等一段时间才能提现到新账户。

## 消息与联系

- 通知（/taker/inbox）：平台的消息和发起方的公告。标签"奖励"（/taker/inbox/rewards）只列奖励的消息。右上的按钮可以全部标为已读、筛选（文字、类型、只看未读、日期）和打开通知设置（是否显示推广消息）。
- 与发起方的对话（/taker/conversations）：在已完成 Quiz 的结果页点"联系发起方"，可询问 Quiz 或奖品的事。消息只能是纯文本，请不要发送联系方式。可以关闭对话、屏蔽发起方或举报对话。
- 在 Quiz 页面点"举报这个 Quiz"可告诉我们问题所在；发起方不会知道是谁举报的。
- 推荐好友（/taker/referrals）：有些 Quiz 在你自己回答或通过后提供推荐链接。好友在期限内通过，你就能得到推荐奖励。

## 我的主页（/taker/account）与设置（/taker/settings）

- 我的主页：你的名字、居住地和加入的年月，学分、待领奖品、证书三个数字；点"编辑资料"修改个人资料。下面的标签依次是已答、学分、证书、知识结构图和推荐，各自列出内容并可打开完整的页面。
- 设置（侧边菜单的"设置"）：上面的搜索框按名称查找，下面是以下各项，以及发起方账号、删除账号和退出登录。

- 个人资料：头像、名字和居住地。点"更换头像"可以选名字的首字或一个预设的头像，点选即保存；头像只有你自己看得到（/taker/account/profile）。邮箱不能在这里更改；需要更改时请联系我们。
- 关于我：可选的信息，用于面向特定人群的 Quiz，以及喜欢的主题。
- 我的认证（/taker/account/certificates）：你持有的证书和公开的认证页面（默认关闭）。
- 登录与安全：密码、两步验证、关联的账号、已登录的设备和最近的登录记录。
- 通知：接收哪些邮件和推送通知，以及邮件的语言。
- App 设置：语言、音效、已屏蔽的内容、安装 App。
- 我的 ID 与店员（/taker/account/id）：你的 ID。发起方用它把你加为交付奖品的店员；店员在店员台（/taker/staff）工作。
- 成为发起方：点亮解锁它的知识结构图节点后，可在账户菜单中申请。"我的发起方账户"（/taker/my-sponsor）显示发起方当天的数据；其他操作在电脑上的发起方页面进行。
- 删除账户（/taker/account/delete）：经过等待期后删除；在此之前可以登录并撤回申请。

## 知识结构图

- 发起方的知识结构图把 Quiz 连接起来。通过一个 Quiz 即点亮它的节点；点亮的节点可以开放其他 Quiz、认证或功能（例如推荐好友、申请成为发起方）。
- "我的知识结构图"（账户菜单，/taker/maps）列出平台的图，以及你答过或点亮过节点的发起方的图，并显示你点亮了几个节点。打开一张图可看到每个节点的状态：已点亮、锁定（要先点亮它需要的节点）、可答（附可答的 Quiz 链接）、等下一场、差条件。方向键可在节点之间移动，列表视图显示同样的内容。
- 发起方的主页（/taker/s/…）显示该发起方的图：登录后带你自己的进度，未登录只显示节点与条件。

## 帮助与条款

- 常见问题的帮助中心：/taker/help。找不到答案时，可以转给客服。
- 问 AI：在帮助中心（/taker/help，设置 → 帮助）的顶部，可以问 App 的使用方法，回答附相关页面的链接；可以标记"解决了"或"没解决"。点"转人工"把对话交给客服，回复会显示在对话中并发到收件箱。以前的对话在"我的对话"中。
- 用户条款：/taker/legal/terms。隐私政策：/taker/legal/privacy。有奖活动规则：/taker/legal/contest-rules。
