テイカーとしてアプリを使う方法です。パスはアプリのページです（/taker で始まります）。

## はじめに

- メールアドレスで登録し、届いたリンクを開きます。パスワードや Google でもサインインできます。クイズに回答する前にメールアドレスを確認してください。
- プロフィール（/taker/welcome）に名前と国・地域を入力します。クイズは国・地域ごとに提供されます。
- アプリの下部に「ホーム」（/taker/）、「履歴」（/taker/history）、「アカウント」（/taker/account）があります。

## クイズを探す（ホーム、/taker/）

- ホームには回答できるクイズが並びます。検索、並べ替え（新しい順、報酬、完了者数など）、絞り込み（主催者、主催者の国・地域、報酬、完了者数）が使えます。
- 回答済みのクイズは表示されません。「回答したクイズも表示」をオンにすると表示されます。
- ショート動画：ホームに並ぶ短い動画です。タップすると全画面で見られ、そのまま回答できます。
- 好きなトピック：「アカウント → 私について」（/taker/account/details）でトピックを選び、「好きなトピックだけを表示」をオンにすると、ホームとショート動画がそのトピックのクイズだけになります。
- クイズの言語：「アカウント → アプリの設定」（/taker/account/preferences）で選びます。選ばなければアプリの言語に従います。
- ブロック：クイズの「…」メニューから「興味なし」や、そのクイズの全回・主催者・動画の提供元のブロックができます。ブロックしたものは表示されず、回答もできません。「アカウント → アプリの設定」で解除できます。
- 主催者が求める条件に合う人だけが回答できるクイズもあります。「私について」をくわしく入力すると回答できることがあります。「私について」の回答が主催者に見えることはありません。
- 知識マップにつながったクイズは、必要なノードを点灯すると表示されます。いまいる場所で再生できない動画（中国本土での YouTube など）を含むクイズは「このコンテンツは、いまいる地域ではご利用いただけません」と表示されます。

## 回答する（/taker/p/…）

- クイズのページに問題数、制限時間、最高報酬、公開期間が表示されます。「クイズを始める」で時間の計測が始まります。回答は 1 人 1 回です。
- 先に動画を見る必要があるクイズや、参加費がかかるクイズもあります。参加費は振込できるクドスから支払い、結果にかかわらず返金されません。
- 回答は自動で保存されます。終わったら提出します。時間切れのときは保存済みの回答が提出されます。
- アンケートに正解はありません。すべての問題に答えると報酬がもらえます。
- 結果画面に得点、合格点、合否、報酬、問題ごとの結果が表示されます。
- AI ヘルプはクイズの問題や答えについては手伝えません。

## 報酬

報酬の受け取り方はクイズごとに表示されます。

- クドス：合格するとすぐに「マイクドス」に入ります。主催者の予算が尽きているときは「保留中」になり、主催者がチャージすると支払われます。
- 主催者からの現金：合格するとコードがもらえます。主催者から受け取るときにコードを見せ、アプリで受け取りを確認するか、問題を報告します。期限までに確認か報告をしないと、新しいクイズを始められません。
- 店頭で受け取る賞品：主催者の店で右上のメニューを開き「スキャン」（/taker/scan）をタップし、画面かポスターのコードを読み取って、受け取る賞品をタップします。期限までに受け取ってください。
- デジタル賞品：コード、クーポン、リンクがアプリに表示されます。「賞品を表示」をタップし、使えたら確認、使えなければ問題を報告します。
- 「履歴」（/taker/history）に回答したクイズと結果、報酬が並びます。

## マイクドス（/taker/wallet）

- クドス、主催者の支払い待ち、保留中、振込中のものが表示されます。新しい報酬は振込できるようになるまで数日保留されます。
- 受け取り方法：Stripe（毎日 Stripe のアカウントに振り込まれます）または日本の銀行口座（/taker/wallet/bank：振込はその都度申請し、担当者が確認します。振込ごとに手数料がかかります）。口座を変更すると、しばらく待ってから新しい口座に振り込めるようになります。

## メッセージと連絡

- 受信箱（/taker/inbox）：プラットフォームからのお知らせと主催者からのお知らせです。
- 主催者との会話（/taker/conversations）：完了したクイズの結果画面の「主催者に連絡」から、クイズや賞品について質問できます。メッセージはテキストのみで、連絡先は書かないでください。会話を終える、主催者をブロックする、会話を報告することができます。
- クイズのページの「このクイズを報告」で問題を知らせられます。報告者が主催者に知らされることはありません。
- 友だち紹介（/taker/referrals）：自分で回答または合格すると紹介リンクがもらえるクイズがあります。友だちが期限内に合格すると紹介報酬がもらえます。

## アカウント（/taker/account）

- プロフィール：名前と住んでいる場所です。メールアドレスはここでは変更できません。変更が必要なときはお問い合わせください。
- 私について：あなたのような人に向けたクイズのための任意の情報と、好きなトピックです。
- マイ認定（/taker/account/certificates）：持っている認定証と、公開の認定ページ（オンにするまで非公開）です。
- サインインとセキュリティ：パスワード、2 段階認証、連携したアカウント、サインイン中の端末、最近のサインインです。
- 通知：受け取るメールとプッシュ通知、メールの言語です。
- アプリの設定：言語、効果音、ブロックしたもの、アプリのインストールです。
- マイ ID とスタッフ（/taker/account/id）：あなたの ID です。主催者が賞品を渡すスタッフにあなたを加えるときに使います。スタッフはスタッフ画面（/taker/staff）で作業します。
- 主催者になる：それを開くノードを知識マップで点灯すると、アカウントのメニューから申請できます。「マイ主催者アカウント」（/taker/my-sponsor）には主催者の今日の数字が表示されます。それ以外の操作はパソコンの主催者ページで行います。
- アカウントの削除（/taker/account/delete）：待機期間のあとに削除されます。それまではサインインして申請を取り消せます。

## 知識マップ

- 主催者の知識マップはクイズをつないだものです。クイズに合格するとそのノードが点灯し、点灯したノードでほかのクイズや認定、機能（友だち紹介や主催者への申請など）が使えるようになります。
- 「マイ知識マップ」（アカウントのメニュー、/taker/maps）には、プラットフォームのマップと、回答や点灯をしたことのある主催者のマップが、点灯したノードの数とともに表示されます。マップを開くと、各ノードの状態（点灯済み、ロック中（必要なノードを先に点灯）、回答できます（回答できるクイズへのリンク付き）、次の機会を待つ、条件不足）が見られます。矢印キーでノード間を移動でき、リスト表示でも同じ内容が見られます。
- 主催者のページ（/taker/s/…）にはその主催者のマップが表示されます。ログインしているとあなたの進み具合が、ログインしていないとノードと条件だけが表示されます。

## ヘルプと規約

- よくある質問のヘルプセンター：/taker/help。答えが見つからないときは担当者に質問を引き継げます。
- AI に質問：ヘルプセンター（/taker/help、アカウント → ヘルプ）の上部で、アプリの使い方を質問できます。回答には関係するページへのリンクが付きます。「解決した」「解決しない」で評価でき、「担当者に相談」で会話をサポート担当に引き継げます。返信はその会話と受信箱に届きます。過去の会話は「会話の履歴」にあります。
- 利用規約：/taker/legal/terms。プライバシーポリシー：/taker/legal/privacy。懸賞キャンペーンの規約：/taker/legal/contest-rules。
